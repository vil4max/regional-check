# Release 2.9

Marketing version: 2.9.0. Local build number: 1 for the app and widget extension.
Xcode Cloud assigns the uploaded build number.

This release adds the phone-companion Map tab: a live picture of the upstream
Ukraine alert map, loaded on demand next to the existing Status and Regions
tabs. Free on all surfaces, no CarPlay or JSON-flow changes.

## What's New — English

- New Map tab: a live picture of the alert map for Ukraine, right in the app.
- Matches your light or dark appearance automatically.
- Manual refresh with a clear "Updated" time stamp.
- Free for everyone — no subscription required.
