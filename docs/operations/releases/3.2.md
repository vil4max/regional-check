# Release 3.2 (draft)

Draft for the next submission. The marketing version is proposed, not set: a release that adds a
feature raises `MINOR` (3.1.0 → 3.2.0, [AGENTS.md](../../../AGENTS.md#versioning)), and
`MARKETING_VERSION` stays 3.1.0 until the release commit. What's New, the change table and the
device checklist come with the release commit.

## App Review notes

The paragraph below replaces the 3.0 "In-app purchases" paragraph in App Store Connect
([3.0](3.0.md#app-review-notes)). That paragraph says the app "presents no purchase screen",
which stops being true once Drive Check Pro is visible, and guideline 2.3.1(a) requires new
features to be described with specificity in the Notes for Review.

The other 3.0 paragraphs carry over only after they are checked again against the release
commit. Two of them already describe older behaviour: the Live Activity paragraph predates the
Live Activity's Refresh button (3.1.0, REQ-SURF-009), and the map paragraph predates the reload
in each foreground session (`4364c9c`).

```
In-app purchase: this version adds Drive Check Pro, the non-consumable In-App Purchase regioncheck.pro.cosmetic. It is cosmetic only: the Pro alternate app icon, a gold crown on the Status screen and a gold accent on the selected tab. It unlocks no function.

To reach it, tap the crown at the top right of the Status tab, or Drive Check Pro under Purchases on the Details tab. Both open the same sheet with Buy and Restore Purchases; after the purchase the sheet also has a switch for the Pro icon.

Everything else is free and needs no purchase: the current region's alert status and the alert map, CarPlay, the Live Activity, the widgets and their refresh, the Control Center control, Siri and Shortcuts, and the full summary.

The earlier subscriptions regioncheck.pro.monthly and regioncheck.pro.yearly are no longer offered in the app. A user whose subscription is still active keeps the same cosmetics while it lasts and sees Manage Subscription on the Details tab and in the Pro sheet. Restore Purchases is on the Details tab and in the Pro sheet.
```

## App Store Connect — owner steps

Nothing here has been entered in App Store Connect. Every step is the owner's
([ADR 0016](../../decisions/0016-cosmetic-pro.md): the product ID, display name, price and every
App Store Connect step wait for the owner).

1. **Owner:** create the non-consumable In-App Purchase. Product ID `regioncheck.pro.cosmetic` is
   what the code and the local StoreKit configuration use; a different ID needs a code change
   first.
2. **Owner:** reference name, display name and description in `en`, `uk` and `ru`. The local
   configuration uses "Drive Check Pro" and "The Pro icon, the crown badge and a gold tab accent."
3. **Owner:** price. The local configuration uses 0.99.
4. **Owner:** the In-App Purchase's own review screenshot (the Pro sheet) and review note.
5. **Owner:** add the In-App Purchase to this version's submission.
6. **Owner:** replace the version's App Review notes with the paragraph above and the 3.0
   paragraphs once they are checked again.
7. **Owner:** decide whether `regioncheck.pro.monthly` and `regioncheck.pro.yearly` stay cleared
   for sale, after checking Apple's documentation on what removal from sale does to existing
   subscribers.
8. **Owner:** update the English description's Pro paragraph
   ([app-store-copy.md](../app-store-copy.md)) when the description is next changed.
9. **Owner:** upload the iPhone Duo screenshots: the outer-display set (1398×2034) and the
   inner-display set (2853×2007), from the ignored `.artifacts/iphone-duo-screenshots/`
   ([capture steps](../../../release/screenshots/README.md#iphone-duo-set)). Optional now, it adds
   the product page's Duo badge; required from April 2027 for builds on the iOS 27.1 SDK.
10. **Owner:** accept the updated Apple Developer Program License Agreement before submitting
    (deadline 2026-11-13).
