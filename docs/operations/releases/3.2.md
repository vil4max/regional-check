# Release 3.2

Marketing version 3.2.0, minimum iOS 27. The last planned release of this development cycle.
Drive Check Pro is built but not on sale: the owner decided on 2026-10-20 to ship without its
In-App Purchase, so only an existing owner sees the crown and the Details row (REQ-SURF-007,
amended 2026-10-20). The user-facing changes are in [CHANGELOG.md](../../../CHANGELOG.md#320---2026-10-20).

## App Review notes

Keep the notes entered for 3.1 and replace only their "In-app purchases" paragraph with this one.
It describes what a reviewer sees: no purchase screen, as in 3.1.

```
In-app purchases: this version presents no purchase screen and gates nothing. The subscription products regioncheck.pro.monthly and regioncheck.pro.yearly remain in App Store Connect only for earlier subscribers, whose renewals are still processed and who keep a cosmetic crown and app icon. Restore Purchases, and Manage Subscription while a subscription is active, are on the Details tab.
```

## Owner steps

Each step is the owner's. The agent prepares and waits for a yes before each tag.

1. **Merge** the Pro hide PR and then this release PR, so that this commit is the head of its push
   to `main` and gets its own "Tests" run.
2. **Xcode Cloud:** check that the workflow archives with Xcode 27.1 or later (App Store Connect →
   Xcode Cloud → the workflow → Environment). An older Xcode gives no iPhone Duo layout: then delete
   the iPhone Duo line from What's New below.
3. **TestFlight tag:** `ci_scripts/tf-check.sh origin/main` must print Ready; it prints the tag
   command for `tf-3.2.0-1`. Push it; the TestFlight workflow moves `testflight` and Xcode Cloud
   uploads the build.
4. **Agreement:** accept the updated Apple Developer Program License Agreement (deadline
   2026-11-13), or the submission is blocked.
5. **Submit:** in App Store Connect create version 3.2.0, select the `tf-3.2.0-1` build, paste What's
   New in all three languages, replace the "In-app purchases" paragraph of the App Review notes with
   the one above, attach no In-App Purchase, keep "Automatically release this version" on, and
   submit for review.
6. **Description:** leave the App Store description as it is. The 3.2 draft in
   [app-store-copy.md](../app-store-copy.md) has a Pro paragraph that must not be applied while Pro
   is off sale.
7. **Release tag:** after submission, `git tag -a v3.2.0 -m "Submitted 3.2.0 (build <Xcode Cloud
   build number>)" <commit of tf-3.2.0-1>` and push it; the TestFlight workflow checks it.
8. Optional: the iPhone Duo screenshots (outer 1398×2034, inner 2853×2007, [capture
   steps](../../../release/screenshots/README.md#iphone-duo-set)). Required only from April 2027.

Later, not for 3.2: selling Pro needs the In-App Purchase `regioncheck.pro.cosmetic` in App Store
Connect, `ProAppearance.isOffered = true` and a new release.
