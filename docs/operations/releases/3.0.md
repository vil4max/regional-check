# Release 3.0

Marketing version 3.0.0, minimum iOS 27. The `BUILD` of a `tf-3.0.0-BUILD` tag
counts TestFlight rounds; it is not the build number testers see. Xcode Cloud
assigns that number and writes it into the archive: `tf-3.0.0-4` on `fd3ee4a`
became TestFlight build 3.0.0 (111), which is also what the Details tab shows.

3.0 is a full redesign and a simplification, built around the question the app
exists to answer: what is the current region's alert status? The phone has two
tabs, Status and Details; the region always follows location; CarPlay has one
screen, the status and its update time. The major version marks the scope of the change, not
a single feature. The map is a reference image, never a navigation surface.

## App Review notes

Saved in App Store Connect on 2026-09-21, replacing notes that described the 2.x
app (manual region selection, a paywall, Pro features). Each claim was checked
against the code or Apple's documentation: the region comes from MapKit reverse
geocoding, which is a network service (Apple's `CLGeocoder` documentation: "works
with a network-based service"; MapKit replaces it), so the notes do not call it
on-device; the app declares no background modes and no background or always
location access; provider requests carry no location; there is no analytics SDK
and no developer server.

```
Drive Check is a CarPlay and iPhone utility that shows the air raid alert status of the region of Ukraine the user is in. It is informational only: not navigation, and not a background monitor. The app has no background modes and does not use location in the background.

No account and no sign-in are needed.

Location is when-in-use only, and optional. The app resolves the region with MapKit reverse geocoding. Without location access it falls back to Kyiv and offers a link to Settings. Location is never sent to the developer or to the alert data provider; the app has no server of its own.

Alert data and the alert map come from the public Ubilling endpoint over HTTPS. The map is a static reference image, not interactive and not navigable, and never fetched on a timer: it appears on iPhone only, loads once per session after the status request, and otherwise only on a manual map refresh or when its day/night variant changes. CarPlay shows text only.

In-app purchases: the subscription products regioncheck.pro.monthly and regioncheck.pro.yearly remain in App Store Connect, but version 3.0 presents no purchase screen and gates nothing behind them. Existing subscribers' renewals are still processed. Restore Purchases, and Manage Subscription while a subscription is active, are on the Details tab.

Live Activity: started while the app is open or CarPlay is connected, and ended when the phone goes to the background unless CarPlay is connected. The switch on the Details tab follows the system Live Activities setting for the app.

Alert persistence, which a reviewer testing on an intermittent connection will notice: once a region shows Alert it stays Alert through transient refresh failures and stale data. Only a confirmed all-clear from the provider downgrades it. This is deliberate: the app must not imply safety it cannot confirm.
```
