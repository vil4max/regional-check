# Release 3.0

Marketing version 3.0.0, minimum iOS 27, local build number 1 for the app and
the widget extension; Xcode Cloud assigns the uploaded build number.

3.0 is a full redesign of Status, Regions, CarPlay, widgets, Live Activity,
onboarding, About and Paywall, built around the question the app exists to
answer: is it safe to drive right now? The major version marks the scope of the
redesign, not a single feature. Everything that was free stays free; the map is
a reference image, never a navigation surface.

## What's New — English

```
Drive Check 3.0 is a full redesign, built around one question: is it safe to
drive right now?

• Redesigned Status screen: your region at a glance, with nearby alerts shown
  even while you are under alert
• Redesigned Regions tab with search — find any region in one tap
• CarPlay: an Alert map tab with the regional map as a reference image, the
  number of regions under alert, the affected list, and Refresh on demand
• iPhone: an Alert map row that opens full screen, refreshed on demand — never
  a background poll
• Refreshed widgets and Live Activity: once a region is under alert it stays
  red until a real all-clear arrives
• A new first-launch walkthrough, a redesigned About screen, and a clearer
  prompt when you leave Ukraine
• Faster, steadier launch

Drive Check answers one question — it does not promise navigation, and it does
not track you in the background.
```

## Validation and delivery

Authoritative order and detail:
[redesign-3.0-owner-handoff.md](../redesign-3.0-owner-handoff.md). This section
summarises it and does not compete with it.

1. The release-prep commit carries this note and the `[3.0]` section of
   `CHANGELOG.md`; `MARKETING_VERSION` is already `3.0.0` in every target and
   configuration. Run `just verify` and `just release --check`.
2. Mark the pre-redesign 3.0.0 candidate "do not submit" in App Store Connect
   if it is still submittable; the new build's number must land above it.
3. Push the release-prep commit, then tag it `tf-3.0.0-N` and push the tag.
4. Wait for the build to reach the Friends&Family group in TestFlight.
5. Run the manual pass — section 2 of the owner hand-off.
6. Upload the English screenshot set captured after the last redesign change,
   reviewed by drivecheck-product first.
7. Select the build, paste the What's New copy above and the review notes
   below, and submit.
8. After submission, tag the submitted commit `v3.0.0`.

## App Review notes

```
Drive Check is a CarPlay and iPhone utility for regional alert status —
informational only, not a background monitor, and not navigation.

The alert map, on CarPlay and on iPhone, is a static reference image fetched
over HTTPS from the public Ubilling endpoint. It is not interactive, not
navigable, and not fetched on a timer: only when the driver opens the tab or
row, and on manual Refresh.

No account, no sign-in.

Pro (StoreKit): regioncheck.pro.monthly and regioncheck.pro.yearly unlock a
session Live Activity (it ends when the phone backgrounds unless CarPlay is
connected), extended source detail, widget extras, a pinned secondary region,
and an alternate icon. The current region's alert status stays free on every
surface. Restore Purchases is on the paywall.

Location: when-in-use only, with an on-device reverse geocode to resolve the
region.

Alert persistence, which a reviewer testing on an intermittent connection will
notice: once a region shows Alert it stays Alert through transient refresh
failures and stale data. Only a confirmed all-clear from the provider
downgrades it. This is deliberate — the app must not imply safety it cannot
confirm.
```
