Method

How this is measured

  • One xcodebuild test -enableCodeCoverage YES run per layer in scripts/coverage-layers.txt, plus one with no tests (the launch baseline), all on the simulator from Tooling/runtime.yml.
  • Line data comes from llvm-cov export against RegionalCheck.debug.dylib and the DriveCheckKit framework binary directly — xccov does not attribute the package's dynamic framework to any target.
  • A line executed by app launch cannot be told apart from one executed by a test that also touches it, so it is credited to launch, not to the layer.
  • Regenerate with scripts/coverage-pyramid.sh (or just coverage-pyramid). Update scripts/coverage-layers.txt when a test file's class list changes.
