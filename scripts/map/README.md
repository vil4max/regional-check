# Status map outlines

`RegionalCheck/Resources/UkraineOutlines.json` and `RegionalCheck/Data/UkraineOutlines+Aspect.swift`
are generated by `build-outlines.sh` (MAP-native AC-11). Run it by hand and commit both outputs; the
build never runs it.

- **Source:** geoBoundaries gbHumanitarian UKR ADM1, release pinned to commit `9469f09`
  (`releaseData/gbHumanitarian/UKR/ADM1/geoBoundaries-UKR-ADM1.geojson`). Built on 2023-12-12
  from the OCHA HDX COD-AB data of the State Scientific Production Enterprise "Kartographia",
  2022 boundaries.
- **Licence:** Creative Commons Attribution 3.0 IGO. The app credits the source in Settings
  (MAP-native AC-8).
- **Units:** 27. These are the 24 oblasts, Kyiv city, the Autonomous Republic of Crimea and
  Sevastopol. Ukraine's own borders apply: Crimea and Sevastopol are Ukrainian units.
- **Simplification:** `npx --yes mapshaper@0.7.101 … -simplify 1% weighted keep-shapes`. It runs on
  the whole layer at once, so neighbouring units keep one shared border, and `keep-shapes` keeps
  Kyiv city and Sevastopol.
- **Projection:** equirectangular, with longitude scaled by cos(48.4°) and y pointing down. The
  output is normalised to a width of 1 and rounded to 4 decimals. Kyiv city and Sevastopol are
  written last, so they draw over the units that enclose them.
- **Output (2026-11-13):** 63,687 bytes, aspect ratio 1.503320.
- **Reproduced (2026-11-13):** a second run of `build-outlines.sh` rewrote both outputs byte for
  byte (`git status` showed no change).

`compact_outlines.py` maps each geoBoundaries `shapeID` to the app's id: an `AlertRegion` raw value,
`crimea` or `sevastopol`. Kyiv city and Kyiv Oblast are both named "Kyivska", so the mapping goes
by `shapeID`, not by name. The script fails if the release adds, drops or renames a unit.
