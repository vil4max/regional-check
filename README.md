# Drive Check

CarPlay utility for drivers: see your region’s current alert status without reaching for the phone. Open, glance, close — not a monitor, map, or notification product.

Version 2.2 adds a concise, localized status summary covering the selected region and the country-wide situation. The same glanceable summary is available on iPhone and CarPlay, refreshes with alert data, and falls back to deterministic on-device text when Foundation Models are unavailable. Current-region status remains free.

**Owner:** [vil4max](https://github.com/vil4max) · **Repo:** [vil4max/regional-check](https://github.com/vil4max/regional-check)

## Stack

iOS 26+ · Swift · SwiftUI · Foundation Models · CarPlay · DriveCheckKit (SPM) · App Group · WidgetKit · App Intents · StoreKit 2 · String Catalogs (en/ru/uk) · Swift Testing
